# Security policy

SwarmBench is an offline research library: it opens no network connections
and runs only the code you give it. Agents you register run in your Python
process with your permissions, so only run agents you trust.

## Supported versions

Security fixes are made for the latest released version.

## Reporting a vulnerability

Please report vulnerabilities privately, by email to info@indigma.eu or
through GitHub's private vulnerability reporting on the repository, rather
than in a public issue. We aim to acknowledge reports within five working
days.
